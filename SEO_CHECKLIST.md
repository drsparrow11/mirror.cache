# MIRROR.CACHE SEO Checklist

## Before Publishing

- Confirm the final GitHub Pages URL.
- If it is not `https://sparrowxecho.github.io/cici-mirror-cache/`, replace that URL in:
  - `index.html`
  - `social.html`
  - `robots.txt`
  - `sitemap.xml`
- Keep `site-preview-desktop.png` and `site-preview-social.png` in the site root. They are used for link previews.

## After Publishing

- Open the live site and confirm both pages load:
  - `/`
  - `/social.html`
- Test link previews with any Open Graph preview tool.
- Submit `sitemap.xml` in Google Search Console and Bing Webmaster Tools.
- Add the live URL to Twitch panels, YouTube descriptions, playlist description, and any social bios.
